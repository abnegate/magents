# magents (Cursor plugin)

Shared session bus for Cursor: skill + MCP (`magents mcp`).

## Prerequisite

```bash
brew install abnegate/tap/magents
```

## Install

Repo marketplace: `.cursor-plugin/marketplace.json` (source `plugins/cursor`).
Submit path for cursor.directory / Cursor marketplace publish.

## What it does

Hand off across Claude / Codex / Grok from Cursor without pasting context.
